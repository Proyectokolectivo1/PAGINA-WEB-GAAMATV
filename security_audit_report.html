Descripción del problema: Se detectó una deconstrucción incorrecta del retorno de la función getNoticiasRelacionadas. Nivel de riesgo: 🟠 MEDIO

Recomendación: El código fue corregido exitosamente. Se aconseja mantener los null checks preventivos para el renderizado.
